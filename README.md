# StitchBill marketing website

Static HTML, CSS and JavaScript. Serve the repository root with a static HTTP server; no build or installation is required.

The homepage preserves the approved burgundy-and-cream identity and animated concept hero. Product capabilities remain marked as planned or unverified. Privacy and Terms pages are drafts requiring owner review.

WhatsApp click diagnostics use this browser tab's session storage only. No customer data or analytics events are transmitted; site-wide analytics are not connected.

See [REVIEW.md](REVIEW.md) for validation results and outstanding items. Its local-copy references describe the isolated review environment; test fixtures and baseline copies are not included in this repository.

The canonical domain, robots.txt, sitemap.xml, existing photograph and original archive are preserved. Photograph: https://images.unsplash.com/photo-1441986300917-64674bd600d8 (illustrative, not a StitchBill customer).
